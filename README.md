# FRAME STUDIO

Offline Georgian window and door order editor.

## Usage
Download `index.html` and open it in Chrome or Edge. No server, internet connection or external dependencies required.

Features: SVG visual layout with vertical/horizontal mullions, opening directions, customer/order details, browser localStorage, JSON backup/import, and A4 printing via browser Save as PDF.

## Important
Browser storage is device/browser-specific; regularly export JSON backups. This is an initial compact implementation and needs further testing and refinement before production use.
